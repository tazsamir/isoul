This is a record of practical choices, not a list of every available project. I prefer software that is understandable, documented, exportable and possible to restore.

| Need | App | Experience and notes |
|---|---|---|
| Photos and phone backups | [Immich](https://immich.app/) | A local photo and video library. |
| Films and television | [Jellyfin](https://jellyfin.org/) | Personal media access without depending on one streaming service. |
| Music | [Navidrome](https://www.navidrome.org/) | Stream a music collection you control. |
| Audiobooks | [Audiobookshelf](https://www.audiobookshelf.org/) | Simple access to audiobooks and podcasts. |
| Device synchronisation | [Syncthing](https://syncthing.net/) | Direct synchronisation between devices. |
| Encrypted backups | [Restic](https://restic.net/) | Scriptable, encrypted and verifiable backups. |
| Passwords | [Vaultwarden](https://github.com/dani-garcia/vaultwarden) | Lightweight Bitwarden-compatible server. |
| Notes | [Simplenote](https://simplenote.com/) | The notes service I use. |
| Documents and OCR | [Paperless-ngx](https://docs.paperless-ngx.com/) | Used on Proxmox with real documents. Lightweight in practice, but it depends on a database and needs proper backups. |
| Personal document management | [Papra](https://github.com/baptisteArno/papra) | The document application I currently use. |
| Service monitoring | [Uptime Kuma](https://github.com/louislam/uptime-kuma) | Used in the lab and excellent for monitoring services. |
| Network DNS filtering | [AdGuard Home](https://adguard.com/en/adguard-home/overview.html) | Used because it is available on the router. |
| Network DNS filtering | [Pi-hole](https://pi-hole.net/) | Previously used and a fantastic, simple alternative. |
| Server and PC monitoring | [Beszel](https://github.com/henrygd/beszel) | Used and very good at displaying server and PC information. |

## Tested, but not current choices

- **[FreshRSS](https://freshrss.org/)** — used before as an RSS reader, but not currently deployed.
- **[Forgejo](https://forgejo.org/)** — tested, but not something I would personally use; still worth mentioning because other people use it.
- **[Mealie](https://mealie.io/)** — tested and works well. Adding food and recipes can be tedious, which is an important practical limitation.
- **[BentoPDF](https://github.com/alam00000/bentopdf)** — a lighter PDF option that I prefer over heavier PDF platforms.

This list records experience, not endorsements. Check the [review method](/review-method/) before treating any project as a recommendation.
