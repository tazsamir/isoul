This site documents a real-world attempt to keep useful services, media and personal data under local control.

## Current focus

- A small self-hosted Docker environment
- Local media access with Jellyfin
- Personal photo storage with Immich
- Music and audiobook services
- Local DNS and HTTPS
- Encrypted backups and recovery checks
- Monitoring without automatic updates

The goal is not to replace every cloud service. It is to avoid making any one company the only place where an important service or copy of a file exists.

More detailed build notes will be added as each project is documented.
